# 金刚石复线原因探究报告

**实验/记录员：**马登

**撰写时间：**2026年7月27日

**问题描述/实验目的：**目前，在LT-100传感器激光线窗口上使用金刚石作为保护片，但在实际使用中，出射的激光线存在两条以上的复线，影响观感，严重时影响轮廓提取。为探究产生复线的原因并找到解决方法，开展本实验。

**实验方法：**

本实验从以下方面开展：供应商、姿态、表面检测、镀增透膜、退火、偏振片、安装角度。

# 安装姿态

**测试方法和现象总结：** 

1.  将激光线方向对准金刚石长边方向，对金刚石以不同角度透射。
    
    1.  以短边方向倾斜，无变化。
        
    2.  以长边方向倾斜，副线跟随角度发生变化，在主线上下移动，角度较大时消失。
        
2.  将激光线方向对准金刚石长边方向，对金刚石以不同距离透射，副线依然存在，但随着距离增加，副线逐渐不明显。
    
3.  改变金刚石方向，将金刚石旋转到短边方向，多数金刚石的副线现象减弱。
    
4.  目前所测金刚石均存在副线，但大多数少于4条。

# 退火测试

**思路来源：**给北睿描述了该现象，对方推测是金刚石内部应力未完全释放，建议进行二次退火，以释放应力。

**现象总结：**使激光线透过退火后的金刚石，仍然有复线。

**结论：**退火无法消除金刚石复线。

# 偏振片

**现象总结：**

使用45°线偏振片测试，分别以0°、45°、90°放置在金刚石前方，结果发现仍然有复线。从现象上看，45°和90°场景下，复线变弱，怀疑是激光线透过偏振片后亮度降低，于是将曝光值降低为原来的一半，去除偏振片后，得到的结果与加上偏振片一致。

**结论：**偏振片是通过降低出射光亮度来减弱复线，并不能消除复线。
